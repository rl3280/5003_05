# Jabberwocky Browser Pet — November 17, 2026

## Design decision

The request was clarified as a browser pet rather than a CPX light interaction.
The pet has three reactions: poking its face shows original nonsense verse,
moving the mouse makes it chase the pointer, and offering a sacrifice makes it
leave the play area. An “Invite it back” button resets the encounter.

## Implementation and test

Implemented as a self-contained HTML page in `src/jabberwocky.html`, with its
styles and JavaScript included in the file. The mouse chase starts when the
pointer moves inside the play area, so clicking the sacrifice controls alone
does not start a chase.

Browser testing confirmed the face produces verse, pointer movement triggers
chasing, the sacrifice makes the creature leave, and reset restores the
initial state. No browser JavaScript errors were reported.

## Learning

This version uses browser pointer and click events, which are different from
MakeCode input events on the Circuit Playground Express. The choice of browser
pet was made after clarifying that the request was not for the CPX project.
